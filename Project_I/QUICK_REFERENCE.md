# Quick Reference Guide

## Project Requirements At-A-Glance

### Document
- **Length**: 3-4 pages (excluding figures, charts, references)
- **Sections**: 6 required sections
- **Citations**: Minimum 6 credible sources in APA format

### Datasets (2 Required)

**Dataset A (Primary)**
- ≥ 500 rows (or ≥ 50 for country-level time series)
- 1+ time variable
- 1+ geographic variable for mapping
- 2+ numeric measures
- 2+ categorical dimensions

**Dataset B (Secondary)**
- Shares join key with Dataset A
- Adds new context variables
- Must enable comparisons

**Relationship**
- Demonstrate Relationship, Join, or Blend in Tableau
- Provide clear rationale for approach

### Visualizations (6+ Charts Required)

Must include:
1. ✓ Map
2. ✓ Bar chart
3. ✓ Table
4. ✓ Line chart
5. Your choice
6. Your choice

**Dashboard**
- 3+ charts
- Interactive filters
- Cohesive design

### Submission Files
1. Final report PDF
2. Tableau workbook (.twbx - packaged format)

## Report Writing Checklist

Structure:
- [ ] 1. Introduction & Background (motivation, questions, goals)
- [ ] 2. Datasets (full documentation of both datasets)
- [ ] 3. Data Story (6+ charts with analysis)
- [ ] 4. Summary & Conclusions (findings, limitations)
- [ ] 5. References (6+ sources, APA format)
- [ ] 6. Contributions (if team project)

Content:
- [ ] Research questions clearly stated
- [ ] All variables defined
- [ ] Each chart addresses research question
- [ ] Data sources cited
- [ ] Limitations discussed
- [ ] Course concepts demonstrated

Formatting:
- [ ] 3-4 pages (excluding figures/references)
- [ ] All figures labeled (Figure 1, Figure 2, etc.)
- [ ] Page numbers
- [ ] Professional appearance
- [ ] APA citations throughout
- [ ] No spelling/grammar errors

## Common Mistakes to Avoid

❌ Don't:
- Use incompatible datasets without a join key
- Create charts without clear purpose
- Forget to define variables
- Ignore data limitations
- Submit without testing .twbx file
- Exceed page limit
- Use non-credible sources
- Submit at last minute

✅ Do:
- Start early
- Choose interesting, relevant topic
- Document everything as you go
- Make meaningful comparisons
- Tell a clear story
- Cite all sources
- Proofread multiple times
- Test all files before submission

## Grading Criteria (Typical)

Projects are typically graded on:
- **Data**: Quality and appropriateness of datasets
- **Analysis**: Depth of exploration and insight
- **Visualizations**: Effectiveness and design quality
- **Writing**: Clarity, organization, and professionalism
- **Technical**: Proper use of Tableau and data joining
- **Completeness**: Meeting all requirements

Focus on quality over quantity!
