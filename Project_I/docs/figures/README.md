# Figures Directory

This folder contains all exported charts and figures from Tableau for inclusion in the final report.

## Required Exports

### Individual Charts
- `chart1_map.png` - Map visualization
- `chart2_bar.png` - Bar chart
- `chart3_table.png` - Table visualization
- `chart4_line.png` - Line chart
- `chart5.png` - Fifth chart (your choice)
- `chart6.png` - Sixth chart (your choice)

### Dashboard
- `dashboard.png` - Screenshot of interactive dashboard

## Export Settings

For best quality in your report, use these settings when exporting from Tableau:

1. **Format**: PNG
2. **Resolution**: 300 DPI (for print quality) or 150 DPI minimum
3. **Dimensions**: Width 1200-1600 pixels recommended
4. **Background**: White (unless your design requires different)

## Naming Convention

Use descriptive names that make it easy to identify charts:
- Good: `chart1_map_state_enrollment.png`
- Bad: `Screen Shot 2024-01-15 at 3.14.59 PM.png`

## Tips

- Export charts after finalizing all formatting
- Keep original Tableau files - you can always re-export
- Check that all text is readable at the size you'll use in the report
- Ensure colors are distinct and accessible
- If printing, verify colors look good in grayscale too

## Inserting in Word Document

When inserting in Microsoft Word:
1. Insert → Pictures → This Device
2. Select the figure
3. Right-click → Wrap Text → "In Line with Text" or "Top and Bottom"
4. Add caption: References → Insert Caption
5. Format caption as "Figure 1: Map showing..."
