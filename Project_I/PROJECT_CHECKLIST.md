## 2. Datasets (Section 2)

### Dataset A (Primary/Fact Dataset)
- [ ] **Minimum 500 rows** (or ≥50 for country-level time series)
- [ ] **Time field**: At least one usable time variable (date/month/quarter/year)
- [ ] **Geographic field**: Location variable for mapping (country/state/county/city/ZIP/lat-long)
- [ ] **2+ numeric measures** (count, rate, dollars, temperature, deaths, etc.)
- [ ] **2+ categorical dimensions** (industry, age group, product type, party, etc.)

### Dataset B (Secondary/Context Dataset)
- [ ] **Shares join key with Dataset A** (Country, State, County, ZIP, Year, Month, ID, etc.)
- [ ] **Adds new explanatory variables** (not duplicates)
- [ ] **Provides context** for comparisons

### Dataset Documentation (For EACH dataset)
- [ ] Who collected the data?
- [ ] Who funded the project?
- [ ] Why was the data created? What purpose?
- [ ] Timeline/lineage of the data
- [ ] Variables defined and described
- [ ] Dataset size documented (rows and columns)
- [ ] Locations included in dataset described
- [ ] How datasets help achieve goals explained
- [ ] **Limitations discussed**

### Relationship/Join Requirements
- [ ] Demonstrated **Relationship** between datasets in Tableau (preferred), OR
- [ ] Demonstrated **Join** with clear rationale, OR
- [ ] Demonstrated **Blend** with justification (only if relationship/join not feasible)
